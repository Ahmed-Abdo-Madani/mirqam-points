# مرقام تسويق — مرجع تحليلات المتاجر الإلكترونية

مرقام تسويق (Mirqam Marketing) يجمع تقارير المتاجر المرتبطة، ويعرض المبيعات والمنتجات والعملاء ومصادر الطلبات بحسب البيانات المتاحة. لكل متجر اشتراك وتفويض مستقلان.

## كيف تقرأ تقريرًا قابلًا للمقارنة؟

1. حدّد المتجر والفترة الزمنية والعملة نفسها.
2. راجع حالات الطلبات الداخلة في الإجمالي والاسترجاعات.
3. افصل إجمالي المبيعات عن الربح الذي يحتاج بيانات التكاليف.
4. قارن مصدر الطلب المسجل في المتجر بإسناد منصة الإعلان دون افتراض تطابقهما.
5. عند نقص بيانات العميل أو الموقع، اعتبرها بيانات غير متاحة ولا تستنتجها.

[متابعة عدة متاجر](https://marketing.mirqam.sa/blog/multi-store-dashboard.html) يوضح تنظيم التقارير. [العائد الإعلاني وصافي الربح](https://marketing.mirqam.sa/blog/roas-vs-profit.html) يشرح الفرق بين المؤشرين.

## نموذج تنظيم قياس الحملات لكل متجر

حمّل [سجل تسمية الحملات ومراجعة المقارنة](mirqam-marketing-campaign-register.csv). خصّص سجلًا مستقلًا لكل متجر، مع تثبيت العملة والمنطقة الزمنية والفترة وحالات الطلبات المستبعدة قبل قراءة النتائج.

| الحقل | طريقة الاستخدام |
| --- | --- |
| utm_source | اسم المصدر مثل google أو newsletter، بصيغة ثابتة |
| utm_medium | نوع الزيارة مثل cpc أو email، دون تغييره بين تقارير الحملة |
| utm_campaign | اسم قصير يحدد الحملة وفترتها دون بيانات عميل |
| الإنفاق | مبلغ فعلي من منصة الإعلان، لنفس الفترة والعملة |
| المبيعات المنسوبة | اذكر مصدر الإسناد ونافذته؛ لا تساوِ بينها وبين جميع مبيعات المتجر |
| الطلبات المستبعدة | وضّح الإلغاء والاسترجاع والطلبات التجريبية |

**ROAS = الإيراد المنسوب ÷ الإنفاق** عند إنفاق أكبر من صفر. إذا كان الإنفاق صفرًا فالقيمة غير قابلة للحساب، وليست ربحًا غير محدود. اختلاف نموذج الإسناد قد يفسر اختلاف التقريرين؛ لا تجمع الإيراد المنسوب من منصات متعددة باعتباره إجمالي مبيعات مؤكّدًا.

راجع [دليل تحليلات المتاجر](https://marketing.mirqam.sa/guide.html) و[العائد الإعلاني وصافي الربح](https://marketing.mirqam.sa/blog/roas-vs-profit.html). ملف CSV يدوي ولا يثبت وجود استيراد آلي أو ربط حساب إعلاني.

## الاشتراك والتفعيل

كل متجر له اشتراكه. متجران لا يشملهما اشتراك واحد ولو ظهرت تقاريرهما في حساب واحد. السنة الإضافية تخص المتجر المؤهل نفسه. [شروط العرض السنوي](https://mirqam.sa/services/annual-offer) تحدد الموعد وطريقة التفعيل؛ الإضافات والتخصيص وميزانية الإعلانات ورسوم المزودين منفصلة.
