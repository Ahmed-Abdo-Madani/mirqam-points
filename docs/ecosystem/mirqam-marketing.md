# مرقام تسويق — مرجع تحليلات المتاجر الإلكترونية

مرقام تسويق (Mirqam Marketing) يجمع تقارير المتاجر المرتبطة، ويعرض المبيعات والمنتجات والعملاء ومصادر الطلبات بحسب البيانات المتاحة. لكل متجر اشتراك وتفويض مستقلان.

- [مدونة تحليلات المتاجر](https://marketing.mirqam.sa/blog/index.html)
- [نطاق الخدمة وطريقة البدء](https://mirqam.sa/services/store-analytics)

## كيف تقرأ تقريرًا قابلًا للمقارنة؟

1. حدّد المتجر والفترة الزمنية والعملة نفسها.
2. راجع حالات الطلبات الداخلة في الإجمالي والاسترجاعات.
3. افصل إجمالي المبيعات عن الربح الذي يحتاج بيانات التكاليف.
4. قارن مصدر الطلب المسجل في المتجر بإسناد منصة الإعلان دون افتراض تطابقهما.
5. عند نقص بيانات العميل أو الموقع، اعتبرها بيانات غير متاحة ولا تستنتجها.

[متابعة عدة متاجر](https://marketing.mirqam.sa/blog/multi-store-dashboard.html) يوضح تنظيم التقارير. [العائد الإعلاني وصافي الربح](https://marketing.mirqam.sa/blog/roas-vs-profit.html) يشرح الفرق بين المؤشرين.

## الاشتراك والتفعيل

كل متجر له اشتراكه. متجران لا يشملهما اشتراك واحد ولو ظهرت تقاريرهما في حساب واحد. السنة الإضافية تخص المتجر المؤهل نفسه. [شروط العرض السنوي](https://mirqam.sa/services/annual-offer) تحدد الموعد وطريقة التفعيل؛ الإضافات والتخصيص وميزانية الإعلانات ورسوم المزودين منفصلة.
