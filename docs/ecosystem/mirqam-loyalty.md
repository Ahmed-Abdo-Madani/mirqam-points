# مرقام ولاء — مرجع النقاط والأختام والمكافآت

مرقام ولاء (Mirqam Loyalty)، المعروف في الواجهة أيضًا باسم مرقام نقاط، يساعد النشاط على تنظيم برنامج نقاط أو أختام ومكافآت العملاء وسجل العمليات. متطلبات المحافظ والربط تُراجع حسب حالة تفعيل الحساب.

## تصميم تجربة أولى

1. اختر سلوكًا واضحًا تريد تشجيعه: زيارة متكررة أو شراء مؤهل.
2. قرّر بين نقاط مرتبطة بالمبلغ وأختام مرتبطة بزيارة أو شراء محدد.
3. حدّد شروط الكسب والاستبدال وتكلفة المكافأة وكيفية شرحها للعميل.
4. اختبر الكسب والاستبدال والتصحيح مع صلاحيات الموظفين وسجل العمليات.
5. راجع هوية البطاقة ومتطلبات أي محفظة رقمية أو تكامل قبل إطلاقه.

ابدأ بدليل [تصميم برنامج ولاء](https://loyalty.mirqam.sa/blog/design-loyalty-program.html)، ثم [النقاط أم الأختام](https://loyalty.mirqam.sa/blog/points-vs-stamps.html)، و[تكلفة المكافآت](https://loyalty.mirqam.sa/blog/loyalty-reward-cost.html).

## التفعيل والتخصيص

راجع الباقات المتاحة والسعر النهائي في صفحة الاشتراك الحالية؛ الإضافات والتخصيص تُسعّر بصورة منفصلة. لا تفترض شمول المنصة بعرض سنوي إلا إذا ظهر الاستحقاق في شروط العرض ومسار الاشتراك. ناقش متطلبات التفعيل والربط مع مرقام. ظهور خيار محفظة أو تكامل لا يعني أنه مفعّل في كل حساب. لا يَعِد هذا المرجع بتكامل جاهز أو رسوم اشتراك غير منشورة.
